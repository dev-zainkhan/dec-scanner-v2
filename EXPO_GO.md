# Expo Go

The full beginner guide is **RUN.md**. Start there if the laptop has nothing installed.

Quick command after Node and `npm install` are done:

```powershell
cd D:\fixed-doc-scanner
npx expo start --go --port 8081
```

Scan the QR with Expo Go (SDK 56). Same Wi-Fi.

Expo Go shows the screens. It cannot run Scan or real AdMob banners. For those, build the APK. See RUN.md Part 3.
